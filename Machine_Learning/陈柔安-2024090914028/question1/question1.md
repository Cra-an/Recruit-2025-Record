# 基于梯度下降的函数极小值寻找与系数拟合

## 一、题目描述
本题围绕函数 \( y = 2x^5 + x^4 - 11x^3 + 7x^2 + 2x \)，开展以下任务：
1. 在区间 \( x \in [-0.5, 1.5] \)、\( y \in [-1, 2] \) 上绘制函数图形。
2. 从 \( x \in [-0.5, 1.5] \) 中随机选初始点，用梯度下降法找该点附近极小值点。
3. 可视化梯度下降迭代过程。
4. （附加）将函数系数设为 \([a,b,c,d,e][a,b,c,d,e]\)，用梯度下降法拟合系数并输出，绘制损失函数图像（仅用 NumPy 库）。

- 将 \( x \) 值代入函数，计算对应的 \( y \) 值。

### （二）梯度下降寻找极小值点
**实现步骤**：

- **定义函数与导数**：
  
  - 目标函数：\( f(x) = 2x^5 + x^4 - 11x^3 + 7x^2 + 2x \)。
  - 导数（梯度）：\( f'(x) = 10x^4 + 4x^3 - 33x^2 + 14x + 2 \)（通过多项式求导公式推导）。
  
- **初始化参数**：
  - 学习率：设为 0.01，平衡收敛速度与稳定性，避免过大导致发散、过小导致收敛过慢。
  - 迭代次数：设为 500 次，确保参数能收敛到稳定值。
  - 初始点：用 `np.random.uniform(-0.5, 1.5)` 从指定区间随机选取。
  
- **迭代更新**：
  - 每次迭代计算当前 \( x \) 值对应的导数。
  
  - 按公式 \( x_{\text{new}} = x_{\text{current}} - \text{学习率} \times \text{导数} \) 更新 \( x \) 值。
  
  - 用 `np.clip(x_current, -0.5, 1.5)` 限制 \( x \) 始终在题目规定区间内，避免超出范围。
  
  - 用列表 `x_history` 和 `y_history` 记录每次迭代的 \(x x \) 值及对应 \(y y \) 值，用于后续可视化。

### （四）附加任务：多项式系数拟合
**实现步骤**：

- **生成样本数据**：
  - 用 `np.linspace(-0.5, 1.5, 100)` 生成 100 个 \( x \) 样本点。
  - 在原函数计算结果基础上，添加高斯噪声（`np.random.normal(0, 0.1, size=100)`），模拟真实观测数据的干扰，得到 \( y \) 样本点 `y_sample`。
- **定义模型与损失函数**：
  - 预测函数：\( \hat{y} = ax^5 + bx^4 + cx^3 + dx^2 + ex \)（待求系数为 \( [a, b, c, d, e] \)）。
  - 损失函数：均方误差（MSE）\( \text{Loss} = \frac{1}{n} \sum_{i=1}^n (y_{\text{sample},i} - \hat{y}_i)^2 \)，衡量预测值与真实值的偏差。
- **推导梯度并迭代优化**：
  - 分别计算损失函数对每个系数的偏导数（梯度），如对 \( a \) 的梯度为 \( -2 \times \text{均值}(\text{error} \times x^5) \)（\( \text{error} = y_{\text{sample}} - \hat{y} \)）。
  - 用 `np.random.rand(5)` 初始化 5 个随机系数。
  - 迭代 1000 次，每次按公式 \( \text{参数} = \text{参数} - \text{学习率} \times \text{梯度} \) 更新系数，用列表 `loss_history` 记录每次迭代的损失值。

## 三、关键代码解析

### （一）导数计算代码
导数是梯度下降的核心，直接决定参数更新方向，代码实现如下：
```python
def func_derivative(x):
    return 10 * x**4 + 4 * x**3 - 33 * x**2 + 14 * x + 2
```

### （二）梯度下降迭代公式代码

体现 “沿梯度反方向更新” 的核心思想，分单变量（x）和多参数（系数）两种场景：

```python
# 单变量（x）更新
x_current = x_current - learning_rate * derivative

# 多参数（系数）更新
params = params - learning_rate * gradient
```

### （三）噪声数据生成代码

模拟真实场景中的数据干扰，检验算法在非理想数据下的拟合能力：


## 四、结果分析

1. **函数图形结果**：图形清晰展示了目标函数在 \(x \in [-0.5, 1.5]\) 区间内的起伏形态，可直观观察到 2 个潜在的局部极小值点位置，为梯度下降的初始点选择和结果验证提供参考。
2. **梯度下降收敛结果**：迭代过程中，x 值逐渐稳定在某一固定值，y 值同步趋于极小；结合可视化路径可观察到，x 始终沿函数 “下坡” 方向更新，说明算法有效找到局部极小值点。
3. **系数拟合结果**：损失函数曲线随迭代次数单调递减，最终趋于稳定；拟合得到的系数与真实值 \([2,1,−11,7,2][2, 1, -11, 7, 2]\) 偏差较小，验证了梯度下降在多参数优化中的有效性。

## 五、遇到的问题及解决方案

| 遇到的问题                                             | 解决方案                                                     |
| ------------------------------------------------------ | ------------------------------------------------------------ |
| 学习率过大导致迭代发散（x 超出区间）、过小导致收敛过慢 | 通过多次测试，确定学习率为 0.01，兼顾收敛速度与稳定性        |
| 初始点不同，可能收敛到不同的局部极小值点               | 限制 x 始终在 \([-0.5, 1.5]\) 区间内，并通过多次实验观察结果分布，确保结果符合题目要求 |
| 噪声数据导致拟合精度下降，损失值无法降至 0             | 增加迭代次数至 1000 次，让模型有足够迭代步数在噪声中学习到真实函数的趋 |
